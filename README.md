# Java implementation of the Worlde game

## Guidelines

1. Clone this repository

2. Download `Russian.txt` from [Wordle-Russian-Dictionary](https://github.com/mediahope/Wordle-Russian-Dictionary) and
   save file path

3. Compile and Run the program using main class `ru.aston.hometask.hw5.WordleGame`

4. Make sure you have an internet connection.
